# MC-CDKer-Generator
Minecraft CDK 礼包批量生成工具  
**完美适配 [YanPlugins/CDKer](https://github.com/YanPlugins/CDKer) 插件**

## 介绍
一键批量生成带**权重随机掉落**的 Minecraft 礼包 CDK 兑换码，
自动输出插件可直接读取的 YAML 配置文件 + 纯文本 CDK 码清单，
专为MC服务器定制：节日活动、常驻福利、开服礼包、压测批量码、运营活动批量发码场景全覆盖。

## 核心功能
- 自定义长度高强度随机CDK（默认20位大小写+数字混合）
- 道具池支持**权重概率分配**，稀有物品低概率产出
- 道具数量支持**自定义随机区间**，礼包随机性更强
- 一键生成标准 CDKer 插件专用 yml 配置，开箱即用
- 独立导出纯文本 CDK 列表，方便复制分发、公告发放、群聊批量发码
- 内置全品类精品稀有物资池，涵盖全维度稀缺道具
- 轻量化部署、无冗余依赖、极简一键运行
- 纯净脚本无广告、无后台、本地离线运行安全可靠

## 适配插件
配套插件官方仓库：
https://github.com/YanPlugins/CDKer
兼容 CDKer 全版本导入规则，支持 `/cdk import` 指令直接导入。

## 使用教程
1. 安装项目依赖
```bash
pip install pyyaml
# 或
pip install -r requirements.txt
```

2. 启动生成脚本
```bash
python main.py
```

3. 运行完成自动产出两份文件
- `cdk.yml` → 服务端插件配置文件，直接给CDKer使用
- `cdk.txt` → 纯礼包码清单，用于玩家发放、运营分发

> 这是默认文件名，请根据你在 `config.yml` 中的配置项进行修改。默认值为 `cdk.yml` 和 `cdk.txt`。

4. 部署导入
将 `cdk.yml` 复制至服务端目录：
`./plugins/CDKer/`

5. 游戏内执行导入指令
```
/cdk import cdk.yml append
```

6. 可选操作
复制 `cdk.txt` 内礼包码，用于群服福利、活动抽奖、全员礼包发放。
